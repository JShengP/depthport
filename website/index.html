WHAT THIS SITE IS

A showcase, not a hosted GPU.

GitHub Pages serves static assets. Interactive examples use generated synthetic fixtures; real depth models, RTSP capture, calibrated measurements and saved private Sessions run only in your local DepthPort installation.
