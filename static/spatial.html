04

Calibration & Measurement

Pinhole checkerboard calibration is an offline CLI step. Single scale anchors are not accuracy validation; independent known distances report empirical residuals, not uncertainty bounds.

Camera intrinsics

Use checkerboard images of the same lens, zoom, resolution and uncropped view. The tool writes a local calibration JSON; set CAMERA_INTRINSICS_FILE in .env and restart.

python tools/calibrate_camera.py \
 --images "calib/*.jpg" \
 --corners-x 9 --corners-y 6 \
 --square-mm 25 \
 --output camera_intrinsics.json

Candidate ground plane
