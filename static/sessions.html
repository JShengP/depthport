Keyboard shortcut help

Opening help pauses replay. Close it, then press Space to continue.

Playback and A/B loop

Space
Play / pause saved-frame replay.
O
Toggle tracking boxes and Object IDs without changing playback.
+ / -
Increase / decrease speed: 0.25×, 0.5×, 1×, 2×. Keeps replay playing or paused; stops at either limit.
0
Reset speed to 1×; keeps replay playing or paused.
← / →
Pause and step one saved frame across the full Session.
Home / End
Pause and jump to the first / last saved frame in the full Session, regardless of filters or A/B.
Page Up / Page Down
Pause and jump back / forward 10 saved frames from the shown frame. Clamp to the full Session’s ends; ignore filters and A/B.
A / B
Set A / B from the last fully displayed frame; pause replay.
Shift + A / Shift + B
Pause and jump to the configured A / B endpoint. Requires a valid interval; looping may be off.
L
Toggle A/B looping and pause; press Play to resume.

Bookmarks

F
Focus and scroll to bookmark search, keeping its text and playback state.
1 / 2 / 3 / 4
1: suspected ID switch · 2: occlusion · 3: object crossing · 4: general bookmark (no tags). Keep search text, focus and playback state.
5
Show all tags, keeping search text, focus and playback state.
6
Clear bookmark search text, keeping the tag filter, focus and playback state.
C
Clear search and tag filters, show all bookmarks and focus search; keep saved notes.
Esc
Leave bookmark search for the displayed replay, keeping query and tag filters; pause replay.
Shift+[ / Shift+]
Pause and jump to the first / last bookmark matching the current tag and search filters.
[ / ]
Previous / next matching bookmark using the current filters.
Shift+1 / Shift+2 / Shift+3
Shift+1: suspected ID switch · Shift+2: occlusion · Shift+3: object crossing. Pause and save the shown frame, adding the tag while keeping saved notes/other tags and unsaved drafts.
Shift+D / Shift+Delete
Pause and ask before removing the shown frame’s saved bookmark, including saved note/tags. Cancel keeps it; unsaved drafts stay in this page. Use Shift+D if Shift+Delete is intercepted.
Ctrl + Y / Ctrl + Shift + Z
Pause and confirm redoing the last restored bookmark’s deletion. Cancel keeps redo available; newer saved edits clear it. Keep unsaved drafts. Ctrl+Y, Ctrl+Shift+Z and the Redo deletion button use the same confirmation; the button is disabled when unavailable. Click its target frame number to pause and jump, keeping drafts and filters; unavailable targets are disabled. Saved tags appear without notes.
Shift + R
Use Shift+R outside editors or the Clear return position button to disable Return to previous frame. Keep the shown frame, unsaved notes, playback and review settings. The button works with shortcuts off; unavailable/busy actions are disabled. Successful clearing shows “Return position cleared” with Undo clear. Successful Undo clear shows “Return position restored” with the target frame. It restores only the last cleared position without navigation or changing drafts/playback; a new return position or Session reload discards it. The shortcut is ignored in editors or during IME.
Undo clear / Redo clear
Undo clear / Redo clear show their own target frame position / total and saved #index beside each button. Targets follow the return history, not the shown frame or filters; temporarily blocked targets are marked unavailable. Click a target frame number, or press Enter/Space on it, to pause and jump to that exact snapshot while keeping drafts and review settings. Missing/busy targets are disabled. This only navigates; it does not restore, clear or replace return history. No notes are shown.
Shift + U
Shift+U or the Redo clear button clears only the just-restored return position again and shows Return position cleared. The button works with shortcuts off and disables without available restored history or while busy. Keep the shown frame, unsaved notes, playback and review settings; U can restore it again. The shortcut is ignored in editors, during IME, with shortcuts off or without available restored history/while busy.
U
Press U outside editors to restore the last cleared return position, keeping the shown frame, unsaved notes, playback and review settings. Success shows Return position restored with the target. Ignored during IME, with shortcuts off, or without an available position/while busy. The Undo clear button also works with shortcuts off.
R
Press R outside editors, or use Return to previous frame, after a successful target jump. Pause and return to the previously shown frame, keeping drafts and review settings. One return position per page/Session; success consumes it, failure allows retry. Disabled without a position or while busy.
Ctrl + Z
Pause and restore the last successfully deleted bookmark’s saved note and tags in this Session. One undo per page; refresh or Session change clears it. Keep drafts and newer bookmarks. The Undo deletion button does the same and is disabled when unavailable. Click its target frame number to pause and jump, keeping drafts and filters; unavailable targets are disabled. Saved tags appear without notes.
Shift+4
Pause and save the shown frame as a general bookmark: clear saved tags, keep the saved note and unsaved drafts.
Shift+M
Pause and save a general bookmark for the shown frame. Keep existing saved notes/tags and unsaved drafts; no editor focus change.
M
Pause and focus the shown frame’s bookmark note.

Notes

Ctrl + Enter
Save this frame’s tags and note, only from the note field.
Esc
Leave the note for replay, keeping unsaved edits.
Enter
Insert a new line in the note.

? toggles this panel outside input fields; Esc also closes the panel. Note and search typing never opens help. IME composition does not trigger shortcuts. Ctrl+Enter saves only from the note; Esc returns from the note or bookmark search.
