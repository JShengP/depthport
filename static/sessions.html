DepthPort Session / Replay

DepthPort · Spatial Analysis ·

Manually save completed AI result frames to local storage. No automatic camera recording; replay does not rerun inference.

Keyboard shortcut help

Opening help pauses replay. Close it, then press Space to continue.

Playback and A/B loop

Space
Play / pause saved-frame replay.
+ / -
Increase / decrease speed: 0.25×, 0.5×, 1×, 2×. Keeps replay playing or paused; stops at either limit.
0
Reset speed to 1×; keeps replay playing or paused.
← / →
Pause and step one saved frame across the full Session.
Home / End
Pause and jump to the first / last saved frame in the full Session, regardless of filters or A/B.
Page Up / Page Down
Pause and jump back / forward 10 saved frames from the shown frame. Clamp to the full Session’s ends; ignore filters and A/B.
A / B
Set A / B from the last fully displayed frame; pause replay.
L
Toggle A/B looping and pause; press Play to resume.

Bookmarks

[ / ]
Previous / next matching bookmark using the current filters.
M
Pause and focus the shown frame’s bookmark note.

Notes

Ctrl + Enter
Save this frame’s tags and note, only from the note field.
Esc
Leave the note for replay, keeping unsaved edits.
Enter
Insert a new line in the note.

? toggles this panel outside input fields; Esc also closes the panel. Note and search typing never opens help. IME composition does not trigger shortcuts. Ctrl+Enter and note Esc only work in the note field.

Sessions

Storage is opt-in (ENABLE_SESSION_STORAGE=1), localhost-only and limited to 20 sessions × 120 frames.
