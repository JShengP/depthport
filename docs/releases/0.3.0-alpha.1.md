# DepthPort v0.3.0-alpha.1 — Sessions, Replay & Offline Tracking

**Experimental Alpha Pre-release / 實驗性 Alpha 預發行版 — development preview / 開發預覽**

## English

This Alpha integrates PR #7 into main and packages the v0.3 experimental development preview. It is not production, physical-camera or tracking-reliability acceptance. Existing Spatial Analysis and viewer features remain available; no tracking default is promoted.

### Included

[Version READMEs: v0.1](../versions/v0.1/README.md) · [v0.2](../versions/v0.2/README.md) · [v0.3](../versions/v0.3/README.md) — differences, architecture and evidence limits.

- Opt-in, manual, local-only Session capture of same-frame RGB/depth/PLY/raw NPY, SHA-256 integrity checks, offline replay and model-grouped depth summaries. `ENABLE_SESSION_STORAGE` defaults to `0`; enable locally and restart before opening `/sessions`.
- Explicit offline YOLO Detect/Segment tracking of saved frames. Simple association remains default; optional Roboflow BoT-SORT runs in an isolated NumPy 2 worker, separate from the NumPy 1 application. No ReID or automatic camera recording; replay does not rerun inference.
- Matching boxes/Object IDs over replay, play/pause/speed/timeline/A-B loops, local bookmarks/notes/tags/search, JSON backup and guarded keyboard help. Unsaved notes and independent histories are retained by the relevant review operations.
- Reproducible Baseline/ByteTrack/BoT-SORT tools, expanded public-sequence studies, parameter sensitivity and added ID-switch/false-positive diagnosis. Only qualified aggregate evidence is distributed.

### Validation and its limits

- Integrated implementation commit `b9b95d4` passed **8/8 main CI jobs** on Ubuntu/Windows × Python 3.11/3.12: [application contracts](https://github.com/JShengP/depthport/actions/runs/39204293374) and [actual model-install/API compatibility](https://github.com/JShengP/depthport/actions/runs/39204293354). Model CI installs the explicit CPU dependency recipe and imports all four real APIs **without pretrained weights or inference**. The version/documentation packaging follow-up is checked separately in [Actions](https://github.com/JShengP/depthport/actions).
- Recorded implementation tests: **306 Python tests passed, 6 opt-in cases skipped**, **11 replay-controller tests**, **606 overlay/Session-review tests**, and **264 matching Session translation keys**. The public manifest, links, source archive and synthetic static build passed. Counts refer to their named runs, not a single combined hardware test.
- Expanded study: **2,700 MOT17 frames / 27 runs**; new-group parameter study: **1,179 frames / 60 runs**; diagnosis reconciles **8 saved runs** with official TrackEval CLEAR. Lower activation can gain coverage while adding switches/FP. Long-occlusion recovery remains unaccepted; defaults stay unchanged.
- Historical fixed detection caches used Ultralytics **8.4.115**; current synchronized requirements use **8.4.176**. The published metrics are not a fresh acceptance run with the newer detector profile. Prior Ubuntu GPU/pilot results remain dated evidence, not new hardware validation for this package.

### Not yet validated / next gates

- Generalised long-occlusion, crossing and moving-camera ID stability; new-track confirmation/competition, detector-localisation and recovery controls need separate independent-sequence tests.
- Fresh Windows pretrained depth/semantic inference and real isolated-worker integration; API import CI is narrower.
- Physical RTSP credentials/codecs/reconnect/latency, sustained VRAM/endurance and NVIDIA hardware WebGL.
- Measured intrinsics, independent ground-truth distances and calibrated metric accuracy. Camera-space Object ID histories are not world trajectories, identity recognition or certified measurements.

### Downloads and public scope

`depthport-0.3.0-alpha.1-source.zip` contains only `PUBLIC_FILES.txt` entries. Check the attached `SHA256SUMS.txt`. Python dependencies and pretrained weights are installed separately; this is a source package, not a standalone binary.

No local `.env`, credentials, private camera captures, recordings, Session bundles, bookmarks/notes, raw sequence frames/GT/per-frame traces, model weights, actual calibration or runtime logs are included. Existing attributed public-example screenshots and aggregate plots retain their documented provenance. ### 本版內容

[各版 README：v0.1](../versions/v0.1/README.md) · [v0.2](../versions/v0.2/README.md) · [v0.3](../versions/v0.3/README.md)，分開說明差異、架構與驗證界線。

- 手動、僅本機 Session 儲存同影格 RGB／深度／PLY／原始 NPY，SHA-256 完整性回放與分模型深度摘要。`ENABLE_SESSION_STORAGE` 預設 `0`，需在本機啟用並重啟後開啟 `/sessions`。
- 明確操作才執行已存影格的 YOLO 偵測／分割追蹤；預設簡易關聯，選配 BoT-SORT 使用獨立 NumPy 2 worker，與 NumPy 1 應用隔離。不做 ReID、不自動錄影，單純回放不重新推論。
- 回放追蹤框／Object ID、播放／暫停／速度／進度條／A-B 循環、書籤備註／標籤／搜尋／JSON 備份與輸入／中文組字防誤觸快捷鍵；相關跳轉保留未儲存備註與各自歷史。
- Baseline／ByteTrack／BoT-SORT 可重現驗證工具、公開連續序列研究、參數比較與新增換 ID／誤追診斷；只發布附條件的彙總。

### 已完成與證據界線

- 整合提交 `b9b95d4` 的 Ubuntu／Windows × Python 3.11／3.12 **main CI 8／8 通過**；應用契約與四模型實際 API 安裝／匯入分開驗證，**沒有下載預訓練權重或執行推論**。版本與文件封裝提交另見 [Actions](https://github.com/JShengP/depthport/actions)。
- 已記錄 Python **306 通過／6 個選配跳過**、回放控制器 **11**、疊圖／Session 檢查 **606**、雙語 Session key **264**，以及公開清單、連結、原始碼／合成靜態站建置通過；這些是各自執行的檢查，不是一次合併的實機驗收。
- 三場景 **2,700 格／27 次**比較、另一組 **1,179 格／60 次**參數驗證，以及 **8 次已存結果**與官方 CLEAR 精確核對。降低啟用門檻的覆蓋改善伴隨更多換 ID／FP，長遮擋恢復仍未通過，維持原預設。
- 舊固定偵測快取使用 Ultralytics **8.4.115**，目前同步依賴為 **8.4.176**；不能把舊分數當新版偵測器驗收。既有 Ubuntu GPU／初測結果保留原日期，不當成本封裝的新實機證據。
