# DepthPort v0.2.0-alpha.1 — Spatial Analysis

**Experimental Alpha / 實驗性 Alpha — GitHub Pre-release**

## English

This alpha adds the **Spatial Analysis Lab** at `/spatial`: pixel depth and camera-space XYZ inspection, sequential same-image four-model comparison, optional YOLO Detect/Segment 2D-to-3D fusion, and camera calibration / candidate-plane / independent error-validation tools. The original viewer, image/RTSP inputs, four depth engines, bilingual UI and raw/final-depth PLY/NPY/ZIP exports remain available. Comparison point-cloud previews now fit their rendered canvas correctly.

### Validation completed

- Ubuntu 24.04 / Python 3.12.3 / RTX 4090 / torch 2.10.0+cu128: fresh isolated installation and real CUDA inference with YOLO26 Depth, DA V2 Small, DA3 Small and DA3Metric Large on one public example image.
- Default application suite: **117 passed, 4 optional real-model tests skipped**. Those same four real-model tests were run separately with genuine cached weights: **4 passed, 0 skipped**. These are separate runs, not 121 default tests.
- Real YOLO26n detection and segmentation, source/frame identity, native depth units and same-frame exports passed. Real browser-to-HTTP checks covered inspection, comparisons, exports and both languages; tested JavaScript errors and 390px horizontal overflow were zero. Browser WebGL used **SwiftShader software rendering**.
- Application CI passed on Ubuntu and Windows with Python 3.11/3.12. This CI uses explicit model doubles and CPU adapter-contract tensors; it does not install and validate all pretrained models on Windows. [Recorded merged-implementation CI](https://github.com/JShengP/depthport/actions/runs/39042967262) · [Current CI runs](https://github.com/JShengP/depthport/actions/workflows/ci.yml).

### Not yet validated / known limits

- Physical IP cameras: RTSP credentials, H.264/H.265 compatibility, reconnection and exposure-to-browser latency.
- A full fresh Windows installation with all four real depth models and semantic weights.
- Measured camera intrinsics, field ground-truth distances, near/medium/far accuracy and calibrated measurement reliability. Estimated meters are not certified distances; DA V2 virtual display depth and DA3 Small relative depth are **not meters**.
- Long-running streaming stability, sustained VRAM usage, repeatable throughput/FPS benchmarks and NVIDIA hardware WebGL rendering.

The recorded real-model checks use **one public still image on one Ubuntu GPU host**. Analysis runs one job at a time and may pause streaming. This alpha does not establish production readiness or safety-distance accuracy. Remaining hardware acceptance is tracked in [issue #6](https://github.com/JShengP/depthport/issues/6).

### Downloads and public scope

`depthport-0.2.0-alpha.1-source.zip` contains only the reviewed `PUBLIC_FILES.txt` entries. Verify it with the attached `SHA256SUMS.txt`. Python dependencies and pretrained weights must be installed separately. The source includes attributed public-sample UI screenshots and curated aggregate validation evidence; it excludes private camera captures, recordings, credentials, local `.env`, model weights, actual calibration, runtime logs and raw export bundles.

## 繁體中文

本 Alpha 新增 `/spatial` **空間分析工作台**：像素深度／相機 XYZ 查詢、同圖四模型依序比較、YOLO 偵測／分割 2D→3D 融合，以及相機標定、候選平面與獨立誤差驗證工具。保留原檢視器、圖片／RTSP、四模型、雙語與原始／最終深度匯出，並修正比較點雲的畫布視角配置。

### 已完成驗證

- 全新 Ubuntu 24.04／Python 3.12.3 獨立環境，在 RTX 4090／torch 2.10.0+cu128 完成四套真深度模型 CUDA 單圖推論。
- 預設應用測試 **117 通過、4 個選配真模型案例跳過**；另外以真權重執行同四個案例，**4 通過、0 跳過**，兩次執行分開記錄。
- 真 YOLO26n 偵測／分割、影像與影格一致性、原生單位、同影格匯出及真正瀏覽器 HTTP 操作通過；雙語、已測 JavaScript 錯誤 0、390px 水平溢出 0。WebGL 使用 **SwiftShader 軟體繪圖**。
- Ubuntu／Windows × Python 3.11／3.12 應用 CI 通過；CI 使用明示模型替身及 CPU tensor，**不代表 Windows 全套真模型安裝通過**。

### 尚未驗證與限制

- 實體 IP Camera 的 RTSP 認證、H.264／H.265、斷線重連與相機曝光到瀏覽器的延遲。
- Windows 乾淨環境的四套真深度模型與語意權重完整安裝。
- 實測相機內參、現場真值距離、近／中／遠距精度與標定後量測可靠性。估計公尺不是認證距離；V2 虛擬展示深度與 DA3 Small 相對深度不能當公尺。
- 長時間串流穩定性、持續 VRAM 使用、可重現吞吐量／FPS，以及 NVIDIA 硬體 WebGL 繪圖。

真模型結果僅涵蓋**單台 Ubuntu GPU 主機與一張公開範例圖**；分析一次執行一個工作，可能暫停串流。本版仍為實驗性 Alpha，不代表正式產品驗收或安全測距能力。後續硬體驗收見 [#6](https://github.com/JShengP/depthport/issues/6)。
