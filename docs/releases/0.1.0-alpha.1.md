# DepthPort 0.1.0-alpha.1

**Source alpha / 原始碼 Alpha — not a production release.**

A local monocular depth and point cloud workbench for RGB images and RTSP cameras. Four selectable backends: YOLO26 Depth, Depth Anything V2 Small, DA3-Small and DA3Metric-Large. English / Traditional Chinese UI and documentation, raw/final-depth exports, explicit units and a synthetic-only viewer demo are included.

本地單目深度與點雲工作台，支援 RGB 圖片與 RTSP，四模型切換；附英文／繁體中文介面及文件、原始／最終深度匯出、明確單位與合成靜態示範。

The release focuses on packaging, documentation, localization and application contracts. The validation record distinguishes automated fake-backed tests from pretrained inference. Real-model execution, fresh target installation, GPU/physical camera validation, hosted CI and distance accuracy remain unverified. No performance numbers or production safety claims are made.

本版重點為封裝、文件、雙語與應用契約；替身測試和真模型推論分開。真模型、目標設備乾淨安裝、GPU／實體相機、遠端 CI 與距離精度仍未驗證，不提供效能數字或正式安全保證。
