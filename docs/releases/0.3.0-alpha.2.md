# DepthPort v0.3.0-alpha.2 — Compatibility & Version Guides

**Experimental Alpha Pre-release / 實驗性 Alpha 預發行版 — development preview / 開發預覽**

## English

Alpha.2 packages the reviewed updates merged after [Alpha.1](https://github.com/JShengP/depthport/releases/tag/v0.3.0-alpha.1). It retains the v0.3 Sessions, replay, bookmark review and optional isolated BoT-SORT features described in the [Alpha.1 notes](0.3.0-alpha.1.md), plus the original viewer and Spatial Analysis. Session storage remains off by default, simple tracking association remains default, and no tracking profile is promoted.

### Changes since Alpha.1

- PR [#10](https://github.com/JShengP/depthport/pull/10): configure-pages v6, read-only Pages metadata validation in PR builds, and verified manual main deployment of the synthetic-only demonstration site.
- PR [#13](https://github.com/JShengP/depthport/pull/13): FastAPI minimum `0.143.2`, validated both at the minimum and with the current resolved application stack.
- PR [#17](https://github.com/JShengP/depthport/pull/17): shared Hugging Face Hub minimum `0.36.2`, retaining the reviewed Transformers profile.
- PR [#18](https://github.com/JShengP/depthport/pull/18): compatible DA3 geometry floors for e3nn `0.5.9` and Trimesh `4.12.2`; keep SciPy `>=1.17.1,<1.18` and plyfile `>=1.1.3,<1.1.4` to preserve the application's NumPy 1 profile. SciPy 1.18.x and plyfile 1.1.4 require NumPy 2 and remain deferred. The optional BoT-SORT NumPy 2 worker stays separate.
- Bilingual README downloads and separate [v0.1](../versions/v0.1/README.md), [v0.2](../versions/v0.2/README.md), [v0.3](../versions/v0.3/README.md) guides now include a comparison SVG and individual workflow illustrations. These generated schematics are not screenshots, inference output or benchmark evidence. Historical releases remain unchanged.

### Validation and its boundaries

The reviewed integrated commit `09c1f8a` passed [application contracts, 4/4](https://github.com/JShengP/depthport/actions/runs/39211080641), [real model API compatibility, 4/4](https://github.com/JShengP/depthport/actions/runs/39211203960) on Ubuntu/Windows × Python 3.11/3.12, and [Pages build/deployment, 2/2](https://github.com/JShengP/depthport/actions/runs/39211229203). Each dependency PR also passed its own synchronized-head checks before merging. API CI installs the explicit CPU runtime and imports actual APIs **without pretrained weights or inference**. Exact release-packaging commit checks are linked in the GitHub Release.

Local checks include 145 FastAPI minimum-version tests, 42 Hub/adapter contracts, 34 geometry/DA3/export tests, compatible dependency resolution and real numerical/PLY I/O smoke checks. Public manifest, Markdown links, obvious credential patterns, deterministic SVGs, source archive and the synthetic static site were checked. [Curated compatibility record](../validation/v0.3-dependency-followup.json) · [Validation history](../en/validation.md).

No new pretrained inference, hardware, continuous-sequence benchmark or accuracy run was performed for Alpha.2. Historical GPU and public-sequence results retain their original dates and versions. Fixed tracking caches used Ultralytics 8.4.115; application requirements now have a floor of 8.4.176, so old scores are not fresh acceptance of the current detector/dependency stack.

### Still experimental / not yet validated

- Generalised long-occlusion recovery, crossing and moving-camera ID stability; independent confirmation/competition, localisation and recovery experiments remain open. Lower activation can add ID switches/false positives; original tracking defaults stay unchanged.
- Fresh Windows pretrained depth/semantic inference and actual isolated-worker Session integration; import CI does not establish this.
- Physical RTSP authentication/codecs/reconnect/latency, sustained VRAM/endurance and NVIDIA hardware WebGL.
- Measured intrinsics, independent ground-truth distances and calibrated metric accuracy. Camera-space Object ID histories are not world trajectories, identity recognition or certified measurements.

### Downloads and public scope

Download the attached **`depthport-0.3.0-alpha.2-source.zip`** and verify it against **`SHA256SUMS.txt`**. This is a manifest-only source package, not a standalone binary; dependencies and pretrained weights are installed separately. Version/tag: **`v0.3.0-alpha.2`**. Alpha.1 and earlier tags/assets remain unchanged.

Only `PUBLIC_FILES.txt` entries are distributed. No private captures/recordings, `.env` or credentials, Session bundles, bookmarks/notes, raw sequence frames/GT/per-frame traces, model weights, actual calibration or runtime logs are included. Existing attributed public-example screenshots/aggregate plots retain their documented provenance. MOTChallenge data is not redistributed; historical studies retain the recorded non-commercial/reuse conditions. Application code is **AGPL-3.0-only**; upstream code, weights and imagery keep their own terms. [Third-party notices](../../THIRD_PARTY_NOTICES.md) · [Asset provenance](../assets/README.md).
