# 紀錄驗證證據，不做虛假的排行榜
[English](../en/benchmarking.md)・[首頁](../../README.zh-TW.md)

使用有權公開的同一張圖片、相同來源 SHA-256 與一致的實測／假設相機內參。明列不同模型的解析度與精度，不假裝相同；冷啟動／下載與暖機後推論分開。記錄 CPU／GPU、VRAM、驅動、OS、Python、套件版本、權重 revision／雜湊、原圖大小、實際網路輸入、樣本數、暖機方式、wall time p50／p95，以及實際量測的峰值記憶體。

[Benchmark CSV 範本](../templates/benchmark.csv)刻意保留空白，未知數據不要填 0。真推論、合成測試、論文結果與硬體實測需分開；RTSP 切換模型使用不同時間畫面，不是同步比較。

用合法場景檢查地面平整度、物體邊緣、反光／透明面與時間尺度漂移。公尺誤差需有實測真值及對齊幾何；相對模型需先定義尺度對齊，不能把 raw 當公尺評分。V2 目前的虛擬幾何不能用於絕對測距誤差。

即時效能需分開接流／解碼、影格年齡、載入、模型／API、點雲打包、傳送與瀏覽器渲染。主機解碼至發布不等於相機曝光至顯示延遲；不能從廠商的單一 kernel 時間推算整套 FPS。
