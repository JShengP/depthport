# Public／Private 專案與資料界線

[English](../en/public-private-boundary.md) · [首頁](../../README.zh-TW.md)

DepthPort 是**公開的實驗性單目深度與空間分析工具**。可公開通用演算法、測試及文件；**不可直接公開客戶／雇主／現場部署資料**。v0.2 開發分支和 Draft PR 也公開。DepthPort 程式碼採 AGPL-3.0-only，**不代表取得公開第三方資料或程式的權利**。

## 可以 Open：先確認有權發布

- 通用 Depth Adapter、Pixel Inspector、依序四模型比較、2D→3D 語意映射、相機標定**演算法**、幾何工具、API、合成測試與雙語文件。
- 合成場景；具有明確再利用授權、來源與必要註明的第三方示範影像。
- 經授權且非機密的實驗方法、彙總 Benchmark、獨立真值誤差與軟體相容性評估。
- 模型名稱與套件依賴。**預設不散布模型權重**，各第三方授權仍有效。

## 應保持 Private：不可加入公開 Repo／分支／Issue／PR／CI 產物

- 客戶監視畫面、人物影像、廠區平面、真實感測器位置、現場錄影、實際相機內外參、非公開測試資料、事件日誌及客戶 Benchmark。
- 帶帳密的 RTSP URL、`.env`、Token、密碼、API Key、私鑰／憑證、內網配置、實際遙測及現場部署參數。
- 未經授權的客戶／公司程式、機密 SOP、商業偵測規則、客戶專用 Adapter、飛控產品整合與未公開 SDK／韌體。

**Private Repo 是存取控制，不是憑證保險箱。** 真正的帳密請用 Secrets Manager 或 CI Secrets，而不是寫入 Git 歷史。

## 推送／審查清單

1. 核對程式、資料、影像、模型權重的著作權、發布許可與第三方授權。
2. 優先使用合成資料；真實資料必須先完成客戶／現場核准、隱私與同意審查、來源授權及保存期限確認。
3. 檢查每個 staged file、binary、commit 歷史、PR 文字、Actions 附件及日誌，避免實際場域資訊洩漏。
4. 執行 `python -m pytest -q`、`python tools/check_release.py` 和兩份雙語檢查；刻意審核 `PUBLIC_FILES.txt`。公開封存程式會擋下常見私人目錄、影像錄影與結果檔，**但不等於完整資安掃描**。
5. 發生洩密時**立即停用／輪替**、通知受影響權利人並走事故處理流程；刪 Commit 不足以抹除公開歷史。
6. 距離結果需區分**相對深度**、**未驗證估計公尺**、**獨立真值的樣本誤差**，不能宣稱單目 AI 是安全認證測距儀。

## 軟體架構界線

**公開 DepthPort → API／PLY／NPY／JSON／ZIP → 私有應用／部署 Repo**。客戶規則、營運資料、實際裝置設定留在私有系統。**將 AGPL 元件放到 Private Repo 並不等於免除授權義務**；必須依實際整合／散布方式評估，必要時另取得合適授權。

新增真實照片到 `docs/assets/` 前仍需個別授權、審核及更新圖片白名單；現行白名單只供合成 UI 預覽。
