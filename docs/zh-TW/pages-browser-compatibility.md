## 逐項驗證

- **B01 載入／完整性：** 53 個公開 HTML／資產／資料／截圖逐位元符合 repo。兩個尺寸的首頁及三版可載入，未觀察到頁面 console error 或 alert。檔案一致與互動行為是不同證據。
- **B02 四模型點雲，未完整：** 兩個尺寸、v0.1／v0.2 的四模型皆顯示真點雲，操作旋轉、滾輪縮放、RGB／深度著色、點大小與重設。現有拖曳介面未執行帶 Shift／右鍵的平移，所以整項仍為 `not_run`；原生觸控也未測。既有 Node Canvas／平移契約通過，不能代替瀏覽器實測。
- **B03 數值查詢：** 40 筆可見原生值／最終 Z／XYZ，比較四模型在 RGB／深度圖中央／邊緣點擊及圖種切換。獨立 Python／NumPy 解碼 little-endian Float32，以保存 K 與像素中心映射計算，全部符合預訂 `abs(error) <= max(5e-6, abs(expected)*5e-7)`；顯示查詢最大絕對誤差 **4.9417114e-7**。不從預覽顏色反推數值。
- **B04 語意查詢：** 16 筆四模型×兩尺寸×Segment／Detect 公車檢查。可見遮罩／ROI 子點雲、信心值、有效對齊像素數及 Z 中位數，以獨立 RLE／框映射及保存最終深度核對；中位數最大顯示誤差 **4.2369080e-7**。遮罩是模型預測，Detect 是近似框，不是真值。
- **B05 回放：** `obj-0005` 在 **1、6、7、12、19、20、24** 格共 14 筆狀態，另測 **0.5×／1×／2×** 前進／暫停、終點停止與前後邊界。來源32／43／55及時間戳相符；7–19格維持未觀測、Z／XYZ 留白、歷史有缺口，該區間沒有觀測格按鈕；有觀測的保存統計相符。不由此宣稱精確 FPS、吞吐量、身分或長遮擋驗收。
- **B06 雙語／排版：** 初輪16個路徑／語言尺寸檢查無橫向溢出，但寬度檢查漏掉隱藏的手機連結，已另記更正。CSS 修復後，三版導覽在兩語言／尺寸皆可見且在邊界內，6次實際點擊到達正確版本；動態所選物件與未觀測文字可操作。雙語模型／單位識別字是刻意保留。
- **B07 導覽／界線：** 原標題、連結及說明失敗見下方，已修正並本機重驗。新9／209／152／57與舊7／230／125／105保持分開；估計內參、虛擬深度、來源條款與靜態展示界線不變。
- **B08 不支援／備援，未測：** 本引擎原生支援 gzip／WebGL，因此沒有實際進入無 gzip 錯誤或瀏覽器 Canvas 備援。沒有改寫 globals 假造不支援；仍需真正不支援的環境。Node 檢查僅為補充。

## 保留的失敗與修復

1. **F01／B07：** v0.1 標題／metadata 誤寫 v0.2，v0.1 標籤卻連到 v0.3。修正標題／描述及 v0.2／v0.3 正確目的地。
2. **F02／B07：** 英文舊 RGB 參考仍稱原生深度未公開，與上方真實檢查器矛盾。改為引導上方檢查器，來源像素點擊仍可使用。
3. **F03／B06，手機：** 共用窄版 CSS 隱藏第二個導覽目的地。修復重驗時發現，並回到原公開 v0.2 確認 `v0.1` 為 `display:none`。修成版本連結全部保留並可換行；原 B06 手機通過由更正紀錄取代，原檔不覆寫。

修復 commit **`1a61a1b`** 已重新建置，本機重驗兩尺寸／語言的導覽與實際跳轉、初始／點擊後的 RGB 說明、數值／遮罩與缺格回放；額外4筆數值／遮罩獨立比對通過，並新增版本標題／目的地回歸測試。本機測試 **526 通過／92 略過**，Pages 相關 **13 通過**，公開檔案／連結及靜態建置通過。main CI／Pages／公開連結確認另見 PR，不把本機重驗當成另一個瀏覽器或新的部署研究。

初始清單另保留兩個測試工具錯誤：對未展開的原生 option 等待可見，以及離線驗證器混入無影格欄位的工具紀錄；均修正後重跑，不當作產品失敗。舊 localhost 預覽停止後另啟明確的新預覽連接埠，也不算公開網站可用性結果。
