# 操作與疑難排解
[English](../en/usage.md)・[首頁](../../README.zh-TW.md)

## 圖片與相機流程

上傳不超過 12 MB 的 JPG、PNG、WEBP。HTTP 202 僅表示排隊；必須等到完成的影格結果，模型載入完成不等於推論成功。選另一個預設後按**套用模型／重試載入**，會自動重跑保留原圖。匯出含來源 SHA-256，請比較同一檔案，不是不同時間的畫面。

RTSP 在伺服器所在網路執行。模型處理期間保留最新解碼影格；切換模型沿用 reader，等待目前呼叫返回、卸載舊權重，再載入新模型。已開始的推論／下載不能安全地強制中止；返回後以最後一次選擇為準，過期 generation 的結果不發布。

**停止來源**會清除來源與結果，不一定卸載模型。**試用檢視器**停止來源後顯示明示合成資料，停用模型匯出。多個瀏覽器會控制同一狀態。

## 語言

頁面右上角選擇 **English** 或 **繁體中文**。首次載入依序使用 URL 指定、已儲存選擇、瀏覽器語言；不支援的語言回退英文，中文偏好顯示繁體中文。切換時也會更新已存在的語言 URL 參數，避免重新整理後跳回。瀏覽器不允許儲存時不會中斷功能。影像與文字不會傳給翻譯 API。

切換語言不重跑模型、不切換引擎、不重設觀看視角，也不更動數值。後端錯誤與模型識別名稱保留原文，便於排查。

## 幾何與匯出

左鍵拖曳旋轉，右鍵或 Shift 拖曳平移，滾輪縮放。點大小、深度拉伸只影響顯示；非 1.0× 有明確警示。旋轉後看見的空白是原本沒有觀測的區域，不是還原的背面。

PLY 使用 XYZRGB，X 向右、Y 向上、相機朝 −Z。NPY 保存正的相機軸 Z，**不是沿視線的歐氏距離**。同影格 ZIP 含最終深度、`model_raw_depth.npy`、對齊的 `rgb_aligned.png`、metadata 與深度預覽。只有模型真的回傳時才加 confidence／sky；串流期間獨立下載可能屬於不同影格，分析請用 ZIP。

## 常見問題

| 現象 | 檢查項目 |
|---|---|
| HTTP 202 後沒有結果 | 狀態、generation、模型載入／下載錯誤、套件安裝 |
| 權重下載失敗 | 對外連線、proxy、可信任本地權重及正確設定 |
| 指定 CUDA 卻不可用 | venv torch build、驅動、GPU；明確 CUDA 不會靜默改 CPU |
| V2 變形或前後跳動 | p5/p95 展示映射、逐影格尺度、假設內參 |
| DA3 shape 不符 | 配置／權重身分、處理後 resize 及對應內參；不要偷偷裁切 |
| RTSP 無畫面 | Python 主機網路、真實路徑、codec、認證、密碼特殊字元編碼 |
| 瀏覽器顯示後端離線 | 伺服器、port、防火牆、相同 origin 與 Host 允許清單 |
| `Invalid host header` | 將預期的本機／LAN 名稱加入 `DEPTHPORT_ALLOWED_HOSTS`，不用 `*` |
| WebGL 不可用 | Canvas2D 較慢；另驗證瀏覽器與 GPU 設定 |
| 全部點消失 | 深度範圍、信心百分位與天空過濾 |
| 靜態示範不能上傳／接流 | 正常行為：靜態示範沒有後端或 AI |

截圖與日誌需移除密碼。即使 Python 錯誤已遮蔽 RTSP，底層 OpenCV／FFmpeg 訊息仍可能包含連線細節。
