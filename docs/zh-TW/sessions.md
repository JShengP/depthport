# v0.3 研究版 — 手動 Session 儲存與離線回放
[English](../en/sessions.md) · [首頁](../../README.zh-TW.md)

**狀態：實驗性開發分支，尚未合併／發布，實體相機驗收仍待完成。** v0.2 Spatial Analysis 保留不變；v0.3 新增**手動、選擇啟用、僅本機**的影格封存與回放工具。它**不會**自動錄製 RTSP 影片或進行位姿補償的像素／3D 追蹤。單純回放不會重新執行深度估計；只有使用者另外按下離線追蹤分析時，才會對已保存的 RGB 影格執行 YOLO Detect／Segment。

**2026-10-17 初步驗證：** 公開影片的 24 影格 Session 流程已通過真 CUDA 深度、CPU YOLO 偵測／分割、完整性與回放；另完成含 Roboflow Trackers 的 179 影格比較。見[條件、結果與限制](tracking-evaluation.md)。這些不代表實體相機或公尺精度驗收。


**2026-10-18：** Session 已支援選配 [Roboflow BoT-SORT worker](tracking-worker.md)，以獨立 NumPy 2 環境執行；預設仍為簡易關聯。

## 啟用方式

1. 使用 v0.3 開發分支，依原安裝文件準備 DepthPort 環境。
2. 在**本機** `.env` 設定 `ENABLE_SESSION_STORAGE=1`，再重啟伺服器。預設 `0`（關閉）；不可在無登入的公開服務上啟用。
3. 執行 `bash RUN_UBUNTU.sh` 或 `RUN_WINDOWS.bat`，開啟 `http://127.0.0.1:8000/sessions`。建立 Session，並在主頁真模型產生影格後，手動點選 **儲存最新影格**。
4. 選取影格並點選**回放**，即讀回 RGB、深度預覽和抽樣的 XYZRGB 點雲，**不呼叫模型**。下載原本同影格 ZIP，仍可取得 `model_raw_depth.npy`、最終深度 NPY、PLY、相機內參、單位與選配分析報告。

## 資料與限制

- 儲存位置：`outputs/sessions/<UUID4>/session.json` 加上每次的 `frame-00001.zip` 等，**不在 Git、static 或 Pages**。
- 建立 Session 和保存每個影格均需明確操作；不設計背景計時錄影，也不保存原始 RTSP 帳密網址。
- `session.json` 紀錄時間、來源類型、frame ID、模型、原生深度單位、可用時的圖片 Hash、深度摘要與 ZIP SHA-256；不包含串流網址。
- 限制：**每 Session 120 影格／256 MiB**、最多 **20 Session**、單影格 ZIP 最多 **20 MiB**。空間不足時回報錯誤，**不會自動刪除舊資料**。
- 會驗證 ZIP Hash、格式與路徑。儲存檔案使用系統支援的私人檔案權限，應視作包含敏感影像的本機資料。
- 時序摘要只比較同引擎、同深度單位的影格深度中位數，**不是**物件軌跡、跨視角配準、世界座標或經驗證的公尺漂移。

## 語意物件追蹤（離線開發功能）

在 `ENABLE_SESSION_STORAGE=1` 的本機模式下，先手動儲存同一 Session 的 2～24 張影格，再於 `/sessions` 選擇 **實例分割**或**方框區域**，按下「分析已存影格」。此功能明確由使用者啟動，**僅在 CPU 上執行 YOLO Detect／Segment**，避免與現有 GPU 深度工作執行緒同時載入另一個模型；第一次執行可能下載 YOLO 權重。原本保存的深度直接讀回，**不會重新執行深度估計、不會自動錄製 RTSP 或上傳資料**。

分析每張 ZIP 都會重新核對 SHA-256，確認 RGB／Depth 大小及相機內參，再把 YOLO 的遮罩或框對應到原本的深度數值。使用同類別、2D IoU 與有限的中心像素位移關聯物件；連續出現者取得 `obj-0001` 等 ID。若來源類型、深度模型、單位、相機幾何或影像解析度改變，ID 將重新分配。遮擋、交錯、漏檢都可能讓 ID 斷裂或切換。**這不是人員身份辨識或 ReID。**

每筆物件紀錄包含 Session 影格索引、原始 Frame ID／時間、2D Bounding Box、Pixel Centroid、類別／信心、原生深度中位數、由相機內參反投影的 **Camera XYZ 中位數**。單純 Detect 的方框會包含背景，不能當成完整物件輪廓。相對深度仍非公尺，估計公尺也**未經真值驗證**。不同影格 Camera XYZ 的變化**不是世界座標軌跡、速度或安全距離**，也沒有相機位姿補償。

工作完成後，只在本地 Session 目錄寫入 `tracking.json`，可於網頁查看及匯出。新增影格後原報告會標記過期，需要重新手動執行。每次最多取最近 24 張已存影格、每張最多 20 個物件；同一時間只執行一項追蹤分析，不會自動刪除既有 Session。

### Tracking 驗收／Benchmark

用[離線 Tracking 驗收工具](tracking-evaluation.md)將本地 `tracking.json` 與人工 Ground Truth 配對，依遮擋、交會、漏檢等情境統計 Object ID Switch、TP／FP／FN 與 Fragmentation。合成 CI 結果不代表真實影片測試；本功能不會錄影、上傳或重新執行模型。

## 在回放影像檢查追蹤 ID

追蹤完成後，按「**回放已分析影格**」開啟該報告的第一格。對齊 RGB 影像會疊加原始偵測框與「**Object ID · 類別**」標籤；同一個 ID 使用固定顏色，標籤避讓其他標籤時以連線指回原框。可用「**上一格／下一格**」，或直接選擇保存影格回放。目前介面預設分析最後 12 格，因此較早的影格可能尚未分析。

「**疊加追蹤框與 Object ID**」可切換顯示。沒有已確認追蹤偵測的格子不畫框；未分析、缺報告、快照不符或報告過期時只顯示提示，不借用其他影格的 ID。疊圖必須符合 Session、保存序號、Session 總格數與快照 SHA-256，以及模型／單位資訊；即使來源 frame_id 重複，也不會混淆保存影格。切換 Session、重新回放或重跑追蹤時會清除舊疊圖，只有目前選取影格的最新回覆可以顯示。

疊圖使用保存影像的原始像素座標，縮放後仍與影像對齊。回放不重新推論，也不修改 RGB／深度、追蹤報告、原始下載包或幾何資料。遮擋／交會前後的 ID 只能作目視診斷，不代表人的身份或世界座標連續性。瀏覽器驗證使用本機公開序列；截圖、真實影像與逐格標註不放進公開原始碼封裝。

## 連續播放保存影格

先回放一格，或按「**回放已分析影格**」，再使用 RGB 影像上方的「**播放／暫停**」。速度提供 **0.25×、0.5×、1×、2×**，預設 **1× 目標為每秒 5 個保存影格**；這是固定預覽節奏，不是原始影片 FPS，也不代表手動快照之間的實際時間。載入較慢時會放慢，不會為了追上速度而跳格或插補。

自動回放一次只執行一份影格讀取／解碼。下一格尚未就緒時保留上一份完整 RGB／深度／ID，解碼完成後一併更新影像、對應疊圖與點雲。按暫停會停在目前已顯示影格，尚未完成的自動載入不能再切換畫面。調速只影響後續排程，不改變追蹤 ID 或來源時間戳。

手動選格、逐格切換、更換 Session、重新整理、保存影格、建立 Session、重跑追蹤、切到背景分頁或離開頁面都會暫停。未啟用 A／B 循環時，播至最後一格會停止；此時再按播放，會從第一個保存影格重播。播放範圍依保存列表，包含追蹤報告以外的影格；那些影格只顯示尚未分析／缺報告提示，不借用其他格子的 ID。回放不會錄影、重新推論或上傳資料。

## 拖曳回放進度條

「**回放進度**」會顯示目前保存影格位置／總格數，並隨播放、暫停、上一格／下一格及影格選單同步。拖曳時先暫停播放，同時顯示目標位置與目前仍在看的影格；放開後才讀取目標，待 RGB／深度解碼完成，再一起更新對應追蹤框、ID 與點雲。載入中或跳轉失敗時，不會把舊影像標成目標影格。

進度依保存順序計算，不是原始影片時間，也不是來源 `frame_id`。範圍涵蓋整個 Session；追蹤報告以外的影格仍顯示未分析／缺報告提示。可用方向鍵與 Home／End 精確移動。沒有影格或只有一格時停用；拖回目前已顯示影格則不重新讀取。

移動滑桿本身不發出回放請求；快速多次放開只會讓最後目標生效。更換 Session、隱藏頁面會取消舊預覽與待顯示結果。跳轉失敗時保留上一份影像、ID 與已完成進度，並回報錯誤。可見讀數與無障礙文字皆提供中英文；回放資料不會上傳或加入公開原始碼封裝。

## A／B 區間循環

以保存影格位置設定「**A（起始）**」及「**B（結束）**」，或按各端點的按鈕，帶入目前已顯示的影格。預設範圍為第一格至最後一格；勾選「**A／B 循環**」後，依目前播放速度重複播放。兩端都包含在內：B 顯示完成後再讀取 A。區間至少需要兩格，須符合 **1 ≤ A < B ≤ 保存總格數**；啟用循環但區間無效時，會停用播放。

調整端點或切換循環會暫停，並取消尚未顯示的載入結果。再按播放時，若目前影格在區間內就繼續，否則從 A 開始。進度條、保存影格選單及上一格／下一格仍可瀏覽整個 Session；手動跳轉會暫停，並保留 A／B 設定。更換 Session 或重新整理會將端點重設為完整保存範圍，並關閉循環。

啟用「**鍵盤快捷鍵**」後，按 **A** 將起點設為最後完整顯示的保存影格，按 **B** 設定終點，按 **L** 切換「**A／B 循環**」。區間控制項旁會顯示按鍵提示；這些操作都會暫停，再按空白鍵或播放繼續。輸入防護與可用條件詳見[鍵盤快捷鍵](#鍵盤快捷鍵)。

A／B 依保存順序計算，不是來源 frame ID 或實際經過時間。每次循環跳轉仍會核對同影格資料，待 RGB／深度解碼後，一起更新對應框、ID 與點雲。讀取或解碼失敗時，會停在上一份完整影格並回報錯誤。循環只讀取本機封存，不執行推論、不更改追蹤結果，也不上傳資料。

## 影格書籤與備註

按「**標記目前顯示影格**」會先暫停播放、取消待顯示的回放，並標記最後完整顯示的影格。啟用鍵盤快捷鍵時，按 **M** 執行相同操作，並捲動至書籤備註欄、將焦點移入，方便直接輸入。可複選「**疑似換 ID**」、「**遮擋**」、「**物件交會**」，或不選分類作為一般書籤。輸入最多 **1000 個 Unicode 字元**的純文字備註，再明確按下「**保存／更新**」，或在備註欄內按 **Ctrl＋Enter**。每個保存影格最多一筆書籤；「**移除書籤**」可刪除目前顯示影格的已保存書籤。

點選書籤列表即可跳回同一個保存影格，會暫停播放並保留 A／B 區間；RGB／深度、追蹤框／ID 與進度仍依原有完整性檢查一起更新。書籤以 Session ID、保存序號及快照 SHA-256 定位，不以來源 `frame_id` 定位。分類是供後續檢查的人工標記，不代表已確認發生 ID Switch。

未送出的編輯會依確切影格暫存在本頁記憶體，換格後回來仍可繼續編輯。啟用鍵盤快捷鍵時，可在備註欄內按 **Esc** 回到回放，保留草稿；在同一影格按 **M** 可繼續編輯。只有透過按鈕或 **Ctrl＋Enter** 明確執行「保存／更新」才將編輯寫入磁碟；Shift＋M 另可只新增缺少的一般書籤。重新載入網頁會保留已保存備註、捨棄未保存草稿。資料只存於本機 **`outputs/sessions/<UUID4>/bookmarks.json`**，獨立於 `session.json`、原始影格 ZIP 及 `tracking.json`；不加入公開原始碼封裝，也不加入下載的原始影格包或追蹤報告。書籤操作不保存新影格、不執行分析／推論，也不上傳資料。

書籤 API 與回放共用儲存功能啟用及 loopback 限制。GET 與兩種修改操作均回傳完整的 `depthport.session-bookmarks.v1` 文件，內含 `session_id` 與 `bookmarks` 列表。PUT 的 `tags` 可複選且不得重複，值為 `id-switch`、`occlusion`、`crossing`，也可為空列表。PUT 與 DELETE 都須提供同影格的 `snapshot_sha256`；快照無效或不符時拒絕操作，不改動已保存紀錄。

### 篩選書籤與搜尋備註

書籤篩選可選「**全部標籤**」、「**疑似換 ID**」、「**遮擋**」、「**物件交會**」或「**一般書籤**」（未選分類）。輸入關鍵字可搜尋已保存的備註；同時設定分類與關鍵字時，須兩者都符合。搜尋忽略前後空白及英文字母大小寫，並可比對對應的全形字元；整段輸入視為原樣文字，包含標點，不拆成多個詞，也不當成正規表示式。列表顯示符合／總筆數，沒有結果時會提示；「**清除條件**」可回到全部及空白搜尋。

篩選只改變列表與書籤導覽選項，保留目前影格、播放與 A／B 設定、編輯器內容及未保存草稿。點選符合的書籤，仍依原有完整性檢查跳回同影格。搜尋只讀取**已保存備註**；保存或套用 JSON 匯入後會更新結果。即使列表正被篩選，「**匯出 JSON**」仍包含全部已保存書籤。

更換 Session 或重新整理會重設篩選。搜尋關鍵字只留在本頁記憶體，不透過請求送出、不放入網址，也不寫入瀏覽器儲存空間。篩選不保存備註、不執行追蹤，也不上傳資料。

### 逐一檢查篩選後的書籤

回放影像上方與書籤列表旁均有「**上一個書籤／下一個書籤**」，兩處都依目前分類與關鍵字篩選結果，按保存影格順序導覽。按鈕會從最後完整顯示的影格，找出前方／後方最近的符合書籤；目前影格不在結果內也可使用。尚未顯示影格時，「下一個書籤」開啟第一筆結果。該方向沒有結果時停用，不會跳回另一端循環。

位置讀數顯示目前書籤在篩選結果中的序位與總筆數；目前影格不符合時會明確提示。跳轉會暫停播放、保留 A／B 區間與未保存草稿，待目標 RGB／深度解碼完成後，一起更新對應框／ID 與點雲。讀取或解碼失敗時保留上一份完整影格。

書籤跳轉載入時，兩處按鈕都會停用。直接點另一筆書籤、更改篩選或 Session，或手動換格，會取消舊跳轉，避免舊結果蓋過新選擇。這些按鈕只讀取本機保存影格，不修改書籤、備註或 JSON 匯出內容。

### 鍵盤快捷鍵

在非輸入欄位按 **Shift＋D** 或 **Shift＋Delete**，先暫停並顯示確認視窗，再移除**最後完整顯示影格的已保存書籤**，包含已保存備註與標籤。Shift＋Delete 被瀏覽器攔截時可改用 **Shift＋D**；兩者使用相同確認與防護。搭配 Shift 的大小寫 d 都可使用，單按 D 或 Ctrl／Alt／Meta 組合不會移除。「**移除影格書籤**」按鈕也使用相同確認流程。頁面確認視窗預設聚焦「**取消**」，也可按 **Esc** 取消。按「**取消**」會保留書籤；確認或取消後都維持暫停。未儲存草稿仍獨立留在本頁，篩選、速度、疊圖、A／B 與目前影像均保留。必須已有書籤且精確快照有效；沒有書籤、尚未載入、書籤跳轉／寫入中、輸入／編輯欄、中文組字、Ctrl／Alt／Meta、長按重複／已處理／背景頁面、停用開關或說明面板開啟時，不會顯示確認或刪除。確認後會再檢查 Session／快照，只送出一次含識別資料的 DELETE；過期回覆不影響另一個 Session。失敗時保留已存內容與草稿供重試；操作只更改本機書籤檔，不推論或上傳。

在非編輯欄位按 **Ctrl＋Z**，暫停並復原目前 Session **最近一次成功刪除書籤**的已保存備註及全部標籤。本頁記憶體只保留一筆：下一次成功刪除會取代，取消或刪除失敗不會取代。切換影格仍可復原；重新整理、切換 Session、重新載入影格清單或套用書籤匯入後清除。復原成功後用掉此筆，失敗則保留供重試；原始快照仍須相符。不跳轉影格、不更改篩選、速度、疊圖或 A／B，獨立未保存草稿保持不變。同格已重新保存的書籤會保留，並以僅新增操作保護並行寫入；更新時間改為復原時間。備註、搜尋及其他編輯欄內保留原生文字復原；停用、中文組字、長按、背景／已處理事件、開啟對話框、寫入／跳轉／拖曳中或 Ctrl＋Shift／Alt／Meta 組合均不觸發。復原暫存僅留本機，不加入 JSON 備份。

在非編輯欄位按 **Ctrl＋Y** 或 **Ctrl＋Shift＋Z**，暫停並**重做剛復原的書籤刪除**。沿用確認視窗，明確列出復原書籤的影格（切換影格後也一樣），預設聚焦「取消」，Esc 也可取消。取消或失敗保留重做；確認只刪除該筆書籤，保留未保存草稿及檢查設定，並可再次按 Ctrl＋Z 復原。成功保存書籤、另一筆刪除、套用匯入、重新載入影格清單、切換 Session 或重新整理會清除重做。復原的已存內容與快照須仍相符；儲存層在鎖內核對更新時間，另一頁有新修改時回傳 HTTP 409 並保留資料。復原因衝突保留新書籤時不啟用重做。輸入／搜尋欄保留原生文字重做；中文組字、長按／已處理／背景事件、停用、開啟對話框、寫入／跳轉／拖曳中或 Alt／Meta 組合均不觸發。兩個快捷鍵使用相同確認與防護；搭配 Ctrl 的大小寫 Y 都可使用，單按 Y 或 Ctrl＋Shift＋Y 不重做。單筆重做只暫存在本頁記憶體，不匯出或上傳。

書籤編輯區下方的「**復原刪除／重做刪除**」按鈕與 Ctrl＋Z、Ctrl＋Y／Ctrl＋Shift＋Z 共用單筆紀錄。沒有相符的復原／重做紀錄、書籤尚未載入、寫入／跳轉／拖曳預覽中、背景頁面或確認／說明視窗開啟時會自動停用；操作成功、取消、失敗、另行保存或切換 Session 後即更新狀態。關閉「鍵盤快捷鍵」仍可使用按鈕；開關只限制鍵盤觸發的確認。重做一律沿用預設聚焦「取消」且可按 Esc 取消的視窗，並在刪除時核對已復原書籤版本。獨立草稿、篩選與目前回放影格皆保留。

每個歷史操作按鈕旁的即時摘要顯示 Session 影格位置、實際已存影格編號（**#index**）與已保存標籤；無標籤顯示「**一般書籤**」。摘要跟隨歷史紀錄，換格或篩選後仍指向原目標，不取用目前回放影格或未保存草稿的標籤。沒有可用紀錄時顯示「**目前無可操作目標**」；已知目標因對話框、跳轉／拖曳或背景頁面暫時受阻時標示「**暫不可操作**」，寫入中可顯示暫無可操作目標。操作、失敗、重設及語言切換後會更新，並透過按鈕描述供螢幕閱讀器讀取。不包含備註、快照雜湊或 Session 識別碼。

**點擊復原／重做刪除旁的目標影格編號**，會暫停回放並跳到該精確快照；也可原生使用 Enter／空白鍵啟動，關閉鍵盤快捷鍵時仍可點擊。復原目標即使書籤已被刪除仍可跳轉；跳轉及改變篩選都不會復原或刪除書籤。未儲存備註與草稿標籤仍保留在原影格，並保留篩選、速度、疊圖及 A／B。無歷史目標、寫入／跳轉／拖曳中、開啟對話框或背景頁面會停用。Session／快照／歷史檢查避免過期或不符的回覆覆蓋畫面；載入失敗保留上一個畫面並可重試。成功後焦點回到回放，方便繼續快捷鍵檢查。

成功跳到不同的復原／重做目標影格後，可按「**返回跳轉前影格**」，暫停並回放跳轉前最後完整顯示的影格，旁邊會標示返回目標。每次成功跳到不同目標會取代這一筆返回位置；同格或失敗跳轉不取代。返回成功後清除這筆，載入／快照不符時保留位置供重試，並保留目前影像及編輯欄。各影格未儲存備註／標籤、篩選、速度、疊圖及 A／B 皆保留，成功後焦點回到回放。不會復原／刪除書籤，也不重新推論。無位置、寫入／跳轉／拖曳中、對話框或背景頁面會停用；關閉快捷鍵仍可點擊。返回會核對 Session／影格清單世代／快照雜湊；一般換格及書籤編輯不清除，切換 Session、重載影格清單或重新整理頁面後清除。跳轉前若沒有完整顯示的影格，不建立新的返回位置。

開啟「鍵盤快捷鍵」時，在非編輯欄位按 **R**，執行與「返回跳轉前影格」相同的操作。無修飾鍵的大小寫 r 都可使用；Ctrl／Alt／Meta 組合不觸發；Shift＋R 則清除返回位置。備註、搜尋、輸入、選單、可編輯內容及 ARIA 編輯焦點（含 composed path）、中文組字、keyCode 229、長按重複、已處理／背景事件、對話框、無返回位置或忙碌時皆不觸發，也不攔截按鍵。關閉快捷鍵後，按鈕仍可使用。

點擊「**清除返回位置**」，或在非編輯欄位按 **Shift＋R**，可**清除返回位置**，立即停用「返回跳轉前影格」，並在按鈕旁顯示「**已清除返回位置**」。按鈕與快捷鍵清除成功後都會以輔助閱讀即時狀態提示；一般跳格後仍保留。建立新返回位置、成功返回、重新載入 Session／影格清單或重新整理頁面會重設；無可用位置或操作受阻不會誤報成功。不暫停／播放、不跳格、不更改目前影像，也不清除任何影格的未保存備註／標籤；篩選、速度、疊圖、A／B 及復原／重做刪除紀錄皆保留。之後再次成功跳到不同目標仍可建立新的返回位置。Shift＋r 與 Shift＋R 皆可使用；Ctrl／Alt／Meta 組合、輸入／搜尋焦點、中文組字、長按／已處理／背景事件、對話框、停用快捷鍵或無位置／操作中均不生效且不攔截按鍵。關閉鍵盤快捷鍵後，清除按鈕仍可使用；沒有有效返回位置、寫入／跳轉／進度預覽中、背景頁面或確認／說明對話框開啟時自動停用。只清除本頁記憶體，不寫入 HTTP、不推論、不匯出或上傳。

「已清除返回位置」旁會顯示「**復原清除**」。復原成功後，在目標摘要旁以既有即時狀態區顯示「**已恢復返回位置**」，重新啟用「返回跳轉前影格」。提示隨語言切換與一般跳格保留；再次清除、新返回位置、成功返回或重新載入 Session／影格清單會重設，無可用位置或受阻時不會誤報成功。只恢復最近清除的返回位置，不跳格、不暫停／播放、不更改任何未儲存草稿或檢查設定。關閉快捷鍵仍可使用；成功後消耗這一次復原機會，再次清除可建立新機會。一般跳格會保留；建立新返回位置、成功返回、重新載入 Session／影格清單或重新整理頁面則捨棄。沿用 Session／世代／快照雜湊檢查；書籤不可用、寫入／跳轉／進度預覽中、背景頁面或確認／說明對話框開啟時停用。只操作本頁記憶體，不送請求、不儲存，且與復原／重做書籤刪除的紀錄獨立。

開啟鍵盤快捷鍵時，在非編輯欄位按 **U**，執行相同的「**復原清除**」動作並顯示「**已恢復返回位置**」。一般小寫 u 或 Caps Lock 大寫 U 皆可，不搭配 Shift。備註／搜尋／輸入／選單／可編輯內容及 ARIA 編輯焦點（含 composed path）、中文組字／keyCode 229、長按重複、已處理／背景事件、Ctrl／Alt／Meta、對話框、停用快捷鍵或無可用位置／操作中均不生效，也不攔截按鍵。Shift＋U 改用下方的重做清除動作。關閉快捷鍵仍可點擊按鈕；兩種方式都不跳格、不暫停／播放或改動草稿。

點擊「**重做清除**」，或在非編輯欄位按 **Shift＋U**，只**重做清除剛復原的返回位置**；以按鈕或 U 復原後都可使用，Shift＋u／Shift＋U 皆支援。成功沿用清除動作，顯示「**已清除返回位置**」、停用返回按鈕，並可再用 U／按鈕復原。一般跳格保留此資格；新返回位置、成功返回、再次清除、重新載入 Session／影格清單或重新整理頁面會重設。沒有剛復原紀錄時不生效且不攔截按鍵，即使有一般返回位置也不清除；一般位置仍可用 Shift＋R 清除。保留影格／影像、全部草稿、播放、篩選、速度、疊圖、A／B 與書籤刪除紀錄，沿用輸入／搜尋／中文組字／keyCode 229、長按／已處理／背景事件、Ctrl／Alt／Meta、停用快捷鍵、對話框及寫入／跳轉／進度預覽防護。關閉鍵盤快捷鍵仍可使用重做清除按鈕；沒有有效的剛復原位置、寫入／跳轉／進度預覽中、背景頁面或確認／說明對話框開啟時自動停用。不送請求、不寫入、不推論、不匯出或上傳。

在「**搜尋已儲存的備註**」按一般 **Esc**，會暫停在最後完整顯示的快照、取消待顯示影格，再將焦點與畫面移回回放。保留搜尋文字、標籤篩選、符合的書籤、草稿、速度、疊圖與 A／B，並阻止搜尋欄原生 Esc 清空文字。尚無有效且可見的回放時，保留搜尋條件與原焦點，讓待處理工作繼續。此操作只在已啟用且有焦點的搜尋欄及快捷鍵開關開啟時生效；中文組字（含 keyCode 229）、長按重複、已處理／背景頁面事件、Ctrl／Alt／Meta／Shift 組合與說明面板均有防護。不保存、上傳或要求影格，不取消已明確送出的書籤保存；離開後可用回放快捷鍵檢查，再按 **F** 回到保留的搜尋。

按 **F** 將焦點移到「**搜尋已儲存的備註**」並捲動至該欄，保留現有文字，不清空或全選。一般小寫 f 或 Caps Lock 大寫 F 均可，不搭配 Shift；本機書籤載入、搜尋欄啟用後即可使用，不必先顯示回放。F 本身不改變篩選、草稿、播放狀態、速度、影格、疊圖或 A／B，也不取消或啟動待處理工作；取得焦點後輸入文字，才使用既有本機書籤篩選。沿用快捷鍵開關、備註／搜尋／原生及自訂編輯控制項、中文組字、長按重複／已處理／背景頁面、修飾鍵與說明面板防護，Ctrl＋F 仍保留瀏覽器尋找功能。不保存、上傳、推論或要求載入影格。

按 **O** 切換「**疊加追蹤框與 Object ID**」，與滑鼠操作共用核取方塊及精確快照疊圖驗證。一般小寫 o 或 Caps Lock 大寫 O 均可，不搭配 Shift。播放中維持播放、暫停時維持暫停；待載入／解碼影格繼續進行，不取消、不重複要求影格，也不重新推論。速度、顯示的 RGB／深度／點雲、草稿、篩選與 A／B 均保留。尚未顯示快照時可預先切換下次回放的疊圖選項；開啟時不借用過期、缺少或未分析的偵測。沿用快捷鍵開關、備註／搜尋／原生及自訂編輯控制項、中文組字、長按重複／已處理／背景頁面、修飾鍵及說明面板防護；核取方塊本身仍保留原生鍵盤行為。此選項僅留在目前頁面，重新整理恢復預設，不寫入或上傳資料。

按 **Shift＋A／Shift＋B** 暫停並跳到已設定的 **A 起點／B 終點**，不改寫端點或循環開關。兩端必須構成有效區間（**1 ≤ A < B ≤ 保存影格數**）；循環關閉或尚未回放時也可使用，依保存順序選取，不受書籤篩選限制。沿用精確快照顯示路徑，保留速度、草稿與篩選，取消待顯示的自動回放，已顯示該端點時不重載。手動載入／拖曳預覽／書籤跳轉／寫入期間、停用快捷鍵、輸入欄／中文組字、已處理／長按重複／背景頁面、說明面板及 Ctrl／Alt／Meta 組合仍有防護。單按 **A／B** 繼續以目前影格設定端點，**Shift＋L** 不生效；不保存或上傳備註。

按 **Page Up／Page Down** 暫停並從最後完整顯示的影格**往前／往後跳 10 個保存位置**；超出範圍停在整個 Session 的第一格／最後一格，不循環、不受書籤篩選或 A／B 限制。影格序號不連續時依保存順序計算，不按數字差值。尚未顯示快照時保留原生操作；其餘沿用端點／逐格快捷鍵的輸入、中文組字、面板、修飾鍵、停用開關及手動操作期間防護、取消機制與精確快照顯示。保留速度、草稿、篩選與 A／B；若已在邊界，只暫停而不重載，不保存或上傳備註。

按 **Home／End** 暫停並跳到**整個 Session 的第一格／最後一格**，不受書籤篩選或 A／B 限制，依保存順序選取，影格序號不連續也適用。保留 A／B、速度與各影格草稿；若已顯示該端點，僅暫停而不重載。跳轉前取消待顯示的自動回放；與逐格操作相同，手動載入、拖曳預覽、書籤跳轉或寫入期間忽略此鍵，沿用快捷鍵開關、輸入／中文組字／說明面板、長按重複、已處理事件、背景頁面與修飾鍵防護。載入失敗保留最後完整快照與 ID，不保存或上傳備註。

按 **0**（主鍵盤或已開啟 Num Lock 的數字鍵盤）將速度恢復為 **1×**，保留目前播放／暫停狀態、影格、草稿、篩選與 A／B。沿用速度選單的更新方式，已是 1× 時不重設計時，不新增影格讀取、保存或上傳。此鍵沿用快捷鍵開關及備註／搜尋／編輯控制項、中文組字、長按重複、已處理事件、背景頁面與說明面板防護，搭配 Ctrl、Alt、Meta 或 Shift 時不生效。

按 **＋／－** 可在 **0.25×、0.5×、1×、2×** 間逐級加速／減速，到達上下限不循環。支援主鍵盤、數字鍵盤的半形加減號與全形 **＋／－**，允許輸入符號所需的 Shift；Ctrl、Alt、Meta 組合、長按重複及中文組字不生效。速度選單與播放狀態同步更新，沿用選單的計時方式；播放中繼續播放、暫停時維持暫停，不取消或重複載入待解碼影格。草稿、篩選及 A／B 均保留，不新增讀取、保存或上傳。此操作沿用快捷鍵開關及輸入欄防護，說明面板開啟時停用；焦點在速度選單本身時保留原生鍵盤行為。

可使用頁首「**快捷鍵說明（?）**」按鈕，或在非輸入欄位按 **?**，開啟依播放／A-B、書籤、備註分組的操作表。再按 **?**、按「**關閉**」或在面板內按原生 **Esc** 可關閉；尚無 Session 時也能查閱。開啟會暫停並取消待顯示回放，保留目前快照、草稿、篩選及 A／B 設定。關閉後焦點回到原控制項，播放維持暫停，可按空白鍵繼續。面板會限制焦點在其內，避免觸發背景的回放或編輯快捷鍵。

共用快捷鍵開關控制 **?**，支援在多數鍵盤上用 Shift 輸入問號。停用時仍可透過說明按鈕查閱，面板會顯示停用狀態。在備註、搜尋、原生輸入欄或自訂編輯元件中輸入 **?** 不會開啟說明；中文組字、長按、已處理按鍵、背景頁面及 Ctrl／Alt／Meta 組合也會忽略。開啟說明不保存備註、不執行推論，也不上傳資料。

啟用「**鍵盤快捷鍵**」時，按**空白鍵**播放／暫停，按**左／右方向鍵**顯示上一個／下一個保存影格，按 **`[`／`]`** 跳到上一個／下一個篩選書籤。按 **A** 設定區間起點、**B** 設定終點、**L** 切換「**A／B 循環**」，按 **M** 標記目前顯示影格並移入備註欄；在備註欄內按 **Ctrl＋Enter** 保存目前顯示影格的書籤與備註，按 **Esc** 保留未保存編輯並回到回放。書籤篩選旁的核取方塊控制以上全部按鍵，預設勾選，可取消勾選停用；重新載入本頁會恢復預設。偏好只留在本頁記憶體。

方向鍵會先暫停，從最後完整顯示的影格，按整個 Session 的保存順序逐格移動，不受書籤篩選或 A／B 區間限制；到兩端即停止。手動載入、拖曳跳轉、書籤跳轉或寫入書籤期間會忽略方向鍵；自動播放有待顯示影格時，則可先取消再逐格移動。空白鍵沿用播放／暫停按鈕的起播、結尾重播及 A／B 規則，可暫停尚在載入的自動播放，但手動載入或書籤寫入期間不能起播。影像仍依同影格檢查一起更新，並保留 A／B 與未保存草稿。

**A／B** 使用最後完整顯示的影格，不採用尚未顯示的選單選擇或進度條預覽；須已有至少兩個保存影格且已顯示一格。**L** 只須至少兩個保存影格即可使用。這些操作都會暫停播放，取消待顯示的自動播放、拖曳跳轉或書籤跳轉，保留上一份完整影像／ID 與未保存草稿；只修改本頁區間設定，不要求載入影格。端點不會自動交換：若 **A ≥ B**，仍顯示原有驗證提示，啟用循環時不能播放。**L** 只切換核取方塊，不會自動開始播放。可使用一般小寫或 Caps Lock 大寫英文字母；Shift＋A／B 改為跳到既有端點，Shift＋L 及其他修飾鍵組合仍忽略。

**M** 與「**標記目前顯示影格**」按鈕的可用條件相同：目前已顯示的同快照影格及書籤須準備完成，且沒有書籤正在寫入；只有一格的 Session 也可使用。操作會先暫停播放，取消待顯示的自動播放、拖曳跳轉或書籤跳轉，再捲動至最後完整顯示影格的備註欄並移入焦點。保留既有備註、分類、未保存草稿、A／B 與篩選，不採用尚未顯示的選單選擇或進度條預覽。輸入觀察紀錄後，再明確按「**保存／更新**」或 **Ctrl＋Enter**。一般小寫 **m** 或 Caps Lock 大寫 **M** 均可，不搭配 Shift。

**Ctrl＋Enter** 只在書籤備註欄本身有焦點、備註欄已啟用且「**保存／更新**」可用時生效，欄位旁會顯示提示。操作等同按下保存按鈕，以最後完整顯示的快照保存目前分類與備註，保留 A／B、篩選及其他影格草稿，並避免重複寫入。保存失敗時保留草稿，供修正或重試。一般 Enter 仍可換行；搜尋欄、其他欄位或頁面空白處的 Ctrl＋Enter 不生效，也不接受 Meta／Command、Alt 或 Shift 組合。單純輸入或按 M 不會保存。

**Esc** 只在已啟用的書籤備註欄本身有焦點，且目前顯示的快照有效時生效。操作會暫停播放、取消待顯示結果，捲動並將焦點移回回放區，不保存、不清空備註，也不另載入影格。未保存文字與分類仍保留於同一確切影格，備註過長而無法保存時也可離開。回放維持暫停，可立即按空白鍵播放、方向鍵逐格檢查或使用其他回放快捷鍵；回到同一影格按 **M** 即可繼續原有草稿。搜尋欄另有上述 Esc 返回操作；其他控制項的 Esc 不會被攔截，搭配 Ctrl、Alt、Meta／Command 或 Shift 時也不觸發。

除了書籤備註欄內的 **Ctrl＋Enter**，以及備註或書籤搜尋欄內的 **Esc**，快捷鍵在焦點位於備註、搜尋欄、輸入欄、選單、可編輯內容或其他編輯控制項（含 ARIA 編輯元件）時不生效。所有快捷鍵（包含這兩個備註欄操作）均忽略輸入法組字、長按重複、已由其他控制項處理的按鍵及背景頁面；回放與導覽鍵也忽略修飾鍵組合，但明列的 Shift＋A／B、Shift＋方括號跳轉、Shift＋M 與 Shift＋1／2／3／4 快速書籤、Shift＋D／Shift＋Delete 移除、Ctrl＋Z 復原、Ctrl＋Y／Ctrl＋Shift＋Z 確認重做與輸入速度／說明符號所需的 Shift 除外。焦點在按鈕、連結、摺疊標題或其他互動控制項時，空白鍵保留原生操作，避免同時觸發播放。快捷鍵控制本機回放、區間設定與書籤編輯；Ctrl＋Enter、Shift＋M、Shift＋1／2／3／4、Shift＋D／Shift＋Delete 與 Ctrl＋Z 會明確保存、移除或復原本機私人書籤檔，不執行推論、不更改 JSON 備份，也不上傳資料。方括號鍵仍沿用書籤按鈕的最近結果、不循環及載入中防護。

### 書籤 JSON 備份與還原

按「**匯出 JSON**」可將已保存書籤下載到本機。請先保存編輯中的備註，未保存草稿不會匯出。UTF-8 JSON 包含格式版本、Session UUID、保存影格序號、快照 SHA-256、分類、備註及 `updated_at`；不含影像、影格包或追蹤結果。備份留在本機，程式不會自動傳到雲端或 GitHub。

還原時，先選取**原本同一個 Session**，且原有的確切影格須仍存在，再選擇不超過 **1 MiB** 的本機 JSON，按「**預覽匯入**」。確認筆數後才「**套用匯入**」。衝突預設保留本機備註；可明確選擇覆寫，取代匯入影格中不同的備註／分類。兩種方式都保留備份未提及的既有書籤，相同備註／分類不需更新。這只備份備註，不能重建 Session 或缺少的影像。

寫入前會驗證整份檔案，包括格式、Session、快照雜湊、影格序號不重複、分類、備註長度及有效 UTF-8／JSON；任一筆無效即整份拒絕。預覽後若已保存備註改變，須重新預覽才能套用。未保存的編輯草稿仍分開保留；切換 Session 或重新整理會清除所選檔案與預覽。套用時會以原子寫入更新本機私人書籤檔。

API 請直接 POST `depthport.session-bookmarks.v1` JSON，使用 `conflict=keep|overwrite`。`dry_run=true` 回傳版本、合併筆數及合併後文件，不寫入；`dry_run=false` 須在 `If-Match` 提供該版本。匯出／匯入沿用儲存啟用、loopback 與跨來源限制；實際備份、備註及影像不加入公開原始碼封裝。
